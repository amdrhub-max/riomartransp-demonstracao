# RioMar Transportes — Landing page (demonstração)

Página única de transporte executivo, corporativo e para eventos no Rio de Janeiro.

## Estrutura
- `index.html` — página
- `support.js` — runtime da página (obrigatório)
- `image-slot.js` — componente de imagens dos destinos
- `assets/` — logo, hero (desktop e mobile), frota e destinos (WebP otimizados)

## Publicar no GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.

Todos os botões de orçamento abrem o WhatsApp (21) 98865-0909.
